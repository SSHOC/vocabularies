## Title

SSH Open Marketplace Resource Type

## Important!

* The filename becomes in SSHOMP the vocabulary name, therefore use `sshomp-resource-type.ttl`
* There must also be a `@prefix : <namespace>.` declared at the beginning, which then becomes the namespace definition on SSHOMP

## Provenance

* Created within the ECHOES project to replace the former EOSC Resource Category
* Edited in a Google spreadsheet, then converted to SKOS through a Python notebook
* Conversion files in https://github.com/acdh-oeaw/vocabs-curation/tree/main/sshomp-resource-type
